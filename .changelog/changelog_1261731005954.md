## core

- 新增 `print_error`、`get_error_details`（别名 `PrintError`、`GetErrorDetails`）和 `ApiException.response_details`，可直接输出或读取错误的 HTTP 状态码、请求 ID、响应头、响应正文快照和原因链。
- 网关返回 HTML、纯文本或不含 `ResponseMetadata` 的 JSON 等非标准响应时，统一抛出 `ApiException`，`e.status` 为真实 HTTP 状态码，不再固定为 200；请求 ID 可从响应头兜底获取。
- 重试判断支持识别 `__cause__`、`__context__` 和 urllib3 包装内的底层网络原因；STS Provider 仅对 HTTP 429、502、503、504、限流或瞬时错误码以及可识别的网络错误重试。
